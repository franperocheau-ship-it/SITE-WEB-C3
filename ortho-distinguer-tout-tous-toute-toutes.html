Distinguer tout, tous, toute, toutes

Homophones grammaticaux

toute = féminin singulier → devant un nom féminin singulier
toutes = féminin pluriel → devant un nom féminin pluriel

Astuce : regarde le nom qui suit. S'il est féminin singulier → toute.
S'il est féminin pluriel → toutes.

tout = masculin singulier (déterminant ou adverbe invariable)
→ tout le monde, tout le temps, il est tout petit

tous = masculin pluriel (déterminant ou pronom)
→ tous les jours, ils sont tous là

Astuce : si le nom qui suit est masculin singulier → tout.
Si le nom est masculin pluriel ou si c'est un pronom → tous.

tout → masculin singulier : tout le livre, c'est tout
tous → masculin pluriel : tous les livres, ils sont tous partis
toute → féminin singulier : toute la nuit, toute seule
toutes → féminin pluriel : toutes les nuits, elles sont toutes là

Adverbe : tout reste invariable sauf devant un adjectif féminin commençant par une consonne ou un h aspiré
→ il est tout petit MAIS elle est toute petite / elles sont toutes petites
